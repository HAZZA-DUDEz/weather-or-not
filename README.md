# Weather or Not

Weather or Not is a Node.js and Express weather app that uses the Open-Meteo API to show current weather, forecasts, and animated weather scenes.

## Features

- Search weather by city
- Use current location
- Current temperature and weather details
- 7-day forecast
- Dynamic sky background
- Seasonal scenery
- Sun and moon arc
- Moon phase images
- Rain, snow, fog, stars, aurora, and sky event effects

## Technologies Used

- Node.js
- Express.js
- Axios
- EJS
- HTML
- CSS
- JavaScript
- Open-Meteo API
